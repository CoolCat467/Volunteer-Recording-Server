# What does this system need to do?
Track volunteers & volunteer hours for grant purposes

# How would you define success for this solution?
- 99 year old can check in and out easily
- Can export data for grants

# What format does data need to be available in?
Total number of volunteers
Total number of hours
Per category:
    Total number of volunteers
    Total number of hours

# How are people interacting with this system?
Touchscreen, big font, management side can be more complex

# Miscellaneous details
- At midnight, if any unresolved check-in entries exist, automatically
check them out with a flag that this entry needs resolved manually
- Have name association somewhere
- Week intervals run from Sunday to Saturday
- Extras:
    - On Saturday at midnight, send an email with an export about the
    week that just rolled over
